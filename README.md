Future_ML_01:
Model to Forecast Sales or demand using historical business data

Built an ML model that uses historical retail sales data to forecast future monthly sales and generate business insights. Trained on real store sales data from Ecuador spanning 3 years. The model predicts the next 6 months of sales and tells you which months will be busiest and which will be slow.

Tools used: Python, Pandas, NumPy, Scikit-learn, Matplotlib, mean_absolute_error, mean squared_error, ploty.graph_objects, streamlit

Attachment:
- sales_forecast.ipynb- with full code and results
- historical_sales.png- past sales trend
- forecast_vs_actual.png- model accuracy visualization
- future_forecast.png- next 6 months prediction
- visual_app.py - full code for visual interface
- Dashboard URL Access - https://futureml01-rbpwwcwr8esmnioscab2ri.streamlit.app/

Dataset: Store Sales Time Series Forecasting dataset from Kaggle
